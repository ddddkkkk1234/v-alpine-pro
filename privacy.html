KINECTI로 돌아가기

개인정보처리방침

KINECTI는 스키 영상 기반 코칭 리포트 도구입니다. 현재 핵심 분석은 브라우저 로컬 처리를 기준으로 하며, 문의, 광고, 분석 도구, 향후 Premium/결제 기능 사용 시 필요한 범위의 정보가 처리될 수 있습니다.

1. 처리하는 정보

서비스는 사용자가 선택한 영상 파일을 브라우저에서 읽어 재생, 포즈 추적, 캡처, 주석, 리포트 생성에 사용합니다. 현재 기본 분석 흐름에서는 영상 파일을 KINECTI 자체 서버에 업로드하지 않는 것을 전제로 합니다.

브라우저에는 사용자가 입력한 리포트 정보, 코치 메모, 세션 정보, 언어 설정, UI 설정 등이 localStorage 또는 브라우저 저장소에 저장될 수 있습니다.

문의 이메일을 보내는 경우 이메일 주소, 문의 내용, 첨부 파일이 처리될 수 있습니다. 향후 계정, 결제, 리포트 공유, 회원별 기록 기능이 추가되면 이름, 이메일, 결제 상태, 리포트 메타데이터 등 필요한 정보가 추가로 처리될 수 있습니다.

2. 처리 목적

처리되는 정보는 영상 분석 화면 제공, 코칭 리포트 생성, 사용 설정 저장, 오류 대응, 문의 응대, 서비스 개선, 광고 성과 측정, Premium 권한 확인 및 결제 처리에 사용됩니다.

3. 영상과 분석 데이터

사용자가 불러온 영상과 분석 결과는 기본적으로 사용자의 브라우저 환경에서 처리됩니다. 다만 사용자가 직접 이메일로 영상을 보내거나, 향후 서버 저장/공유 기능을 사용하는 경우 해당 기능 제공에 필요한 범위에서 영상 또는 리포트 데이터가 전송될 수 있습니다.

영상에는 본인 또는 타인의 얼굴, 신체, 장소 정보가 포함될 수 있으므로, 타인의 영상을 업로드하거나 공유하기 전 필요한 동의와 권리를 확보해야 합니다.

4. 보관 기간과 삭제

브라우저에 저장된 세션, 메모, 설정 정보는 사용자가 브라우저 저장소를 삭제하거나 서비스 내 초기화 기능을 사용하는 경우 제거할 수 있습니다. 이메일 문의 기록은 응대와 분쟁 대응에 필요한 기간 동안 보관될 수 있습니다.

향후 회원/결제 기능이 도입되면 계정 탈퇴, 결제 취소, 법정 보관 의무에 따른 별도 보관 기간을 고지합니다.

5. 제3자 서비스

서비스 운영 과정에서 Google Analytics, Google Tag Manager, Microsoft Clarity, Google AdSense 등 외부 서비스가 사용될 수 있습니다. 각 서비스는 접속 로그, 쿠키, 기기 정보, 페이지 이용 흐름, 광고 식별자 등을 처리할 수 있습니다.

향후 결제 기능이 제공되는 경우 Lemon Squeezy 등 결제 대행사가 결제 처리를 위해 이름, 이메일, 결제 정보, 세금 관련 정보를 처리할 수 있습니다.

6. 광고 및 쿠키

본 사이트는 Google AdSense 광고를 게재할 수 있습니다. Google 및 제3자 광고 사업자는 광고 제공과 맞춤형 광고를 위해 쿠키, 웹 비콘, IP 주소 또는 기타 식별자를 사용하거나 사용자의 브라우저에 쿠키를 설정하고 읽을 수 있습니다.

사용자는 브라우저 설정 또는 Google 광고 설정에서 맞춤형 광고를 제한할 수 있습니다. Google이 파트너 사이트 또는 앱에서 데이터를 사용하는 방식은 Google 안내 페이지에서 확인할 수 있습니다.

7. 이용자 유의사항

타인의 스키 영상, 강습 영상, 경기 영상 등을 분석하거나 공유할 때에는 관련 법령, 초상권, 저작권, 촬영 동의 의무를 준수해야 합니다. 민감한 개인정보, 결제정보, 의료정보 등은 코치 메모나 문의 내용에 포함하지 않는 것을 권장합니다.

8. 보안

서비스는 HTTPS 환경에서 제공되는 것을 전제로 하며, 결제 또는 서버 기능이 추가되는 경우 필요한 접근 제어와 권한 검증을 적용합니다. 단, 인터넷 전송과 외부 서비스 이용에는 일반적인 보안 위험이 존재할 수 있습니다.
